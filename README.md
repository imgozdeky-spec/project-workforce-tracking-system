# Project & Workforce Tracking System

## 📌 Project Overview

This project is a simplified project and workforce tracking system developed as an Industrial Engineering portfolio project.

The system analyzes project tasks, working hours, overtime, task completion dates, and workload distribution using sample data.

> **Note:** The dataset used in this repository is completely synthetic and does not contain confidential company or employee information.

## 🎯 Objectives

- Track project and task information
- Analyze employee working hours
- Monitor overtime hours
- Identify delayed tasks
- Compare planned and actual completion dates
- Analyze workload distribution across departments
- Generate visual reports

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib
- CSV

## 📊 Analysis

The Python script performs the following analyses:

1. Total working hours by department
2. Overtime hours by employee
3. Identification of delayed tasks
4. Comparison of planned and actual completion dates
5. Visualization of overtime
6. Visualization of department working hours

## 🚀 How to Run

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python src/analysis.py
```

The generated charts are saved in:

```text
outputs/charts/
```
